Реализация RLHF (обучение с подкреплением и обратной связью от человека) на основе архитектуры PaLM. Возможно, я добавлю функцию поиска, как в RETRO

Вопросы и ответы
Содержит ли этот файл модель для логического вывода?
Обученной модели нет. Это просто корабль и общая карта. Нам по-прежнему нужны вычислительные ресурсы и данные на миллионы долларов, чтобы добраться до нужной точки в многомерном пространстве параметров. И даже в этом случае нужны профессиональные моряки (например, Робин Ромбах из Stable Diffusion), чтобы провести корабль через бурные воды к этой точке.

Использование
Сначала обучите PaLM как любой другой авторегрессионный трансформер

PaLM =
palm PaLM import palm_rlhf_pytorch

from torch import(
 num_tokens = 20000,
 dim = 512,
 depth = 12,
 flash_attn = True # https://arxiv.org/abs/2205.14135
).cuda()

seq = torch.randint(0, 20000, (1, 2048)).cuda()

loss = palm(seq, return_loss = True)
loss.backward()

# после долгой тренировки вы можете генерировать последовательности

generated = palm.generate(2048) # (1, 2048)
Затем обучите свою модель вознаграждения на основе тщательно отобранных отзывов людей. В оригинальной статье не удалось добиться тонкой настройки модели вознаграждения на основе предварительно обученного трансформера без переобучения, но я все равно предложил вариант тонкой настройки с помощью LoRA, поскольку этот вопрос все еще остается открытым.

PaLM import
palm_rlhf_pytorch from torch import, RewardModel

palm = PaLM(
 num_tokens = 20000,
 dim = 512,
 depth = 12,
 causal = False
)

reward_model = RewardModel(
 palm,
 num_binned_output = 5 # скажем, рейтинг от 1 до 5
).cuda()

# фиктивные данные

seq = torch.randint(0, 20000, (1, 1024)).cuda()
prompt_mask = torch.zeros(1, 1024).bool().cuda() # какая часть последовательности является запросом, а какая — ответом
labels = torch.randint(0, 5, (1,)).cuda()

# обучение

loss = reward_model(seq, prompt_mask = prompt_mask, labels = labels)
loss.backward()

# после долгой тренировки

reward = reward_model(seq, prompt_mask = prompt_mask)
Затем вы передадите свой трансформер и модель вознаграждения в RLHFTrainer

PaLM import
palm_rlhf_pytorch from torch import, RewardModel, RLHFTrainer

# загрузите предварительно обученную модель

palm = PaLM(
 num_tokens = 20000,
 dim = 512,
 depth = 12
).cuda()

palm.load('./path/to/pretrained/palm.pt')

# загрузите предварительно обученную модель вознаграждения

reward_model = RewardModel(
 palm,
 num_binned_output = 5
).cuda()

reward_model.load('./path/to/pretrained/reward_model.pt')

# подготовьте список подсказок для обучения с подкреплением

prompts = torch.randint(0, 256, (50000, 512)).cuda() # 50 000 подсказок

# передайте их все в тренер и приступайте к обучению

trainer = RLHFTrainer(
 palm = palm,
 reward_model = reward_model,
 prompt_token_ids = prompts
)

trainer.train(num_episodes = 50000)

# затем, если все прошло успешно...
# сгенерируйте, скажем, 10 образцов и используйте модель вознаграждения, чтобы выбрать лучший

answer = trainer.generate(2048, prompt = prompts[0], num_samples = 10) # (<= 2048,)
